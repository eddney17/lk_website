# Customize editor fonts

## Self-hosted files

Place `.ttf` files in this folder using these exact names:

| File | Font |
|------|------|
| `HelloValentica.ttf` | Hello Valentica |
| `DejaVuSerif.ttf` | DejaVu Serif (included) |
| `BakerieRough.ttf` | Bakerie Rough |
| `Bellaboo.ttf` | Bellaboo |
| `Brusher.ttf` | Brusher |
| `Gladiola.ttf` | Gladiola |
| `EspoirSerif.ttf` | Espoir Serif |
| `Malibu.ttf` | Malibu |
| `Ahkio.ttf` | Ahkio |
| `Hangyaboly.ttf` | Hangyaboly |
| `BrittanySignature.ttf` | Brittany Signature |

## Google Fonts (loaded automatically)

Bellota, Dancing Script, Yeseva One, Shrikhand, Bebas Neue, Oleo Script

## System fonts (Windows)

Comic Sans, Impact, Times New Roman — no file needed on Windows.

If your files use different names, rename them or update `customize-item.fonts.scss`.
